# Relato de vulnerabilidades

Reporte vulnerabilidades pelo canal privado do GitHub: [Report a vulnerability](https://github.com/guilhermeestrela10/farmacia-manager/security/advisories/new).

Informe versão ou commit, impacto e passos mínimos para reprodução usando dados fictícios. Nunca envie senhas, tokens, dados pessoais ou dumps de bancos reais. Evite divulgar detalhes exploráveis em issues públicas.

O projeto é mantido como desenvolvimento individual e não oferece SLA de resposta ou garantia de suporte a versões anteriores. A existência deste canal não significa que a aplicação esteja homologada para produção.

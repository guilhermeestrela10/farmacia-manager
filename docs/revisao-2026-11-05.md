# Revisão pontual — 05/11/2026

O acompanhamento automático do repositório foi removido a pedido do usuário. Esta revisão é pontual, baseada na main `6717d9e`, com alterações publicadas em `codex/revisao-geral-2026-11-05`.

## Erros corrigidos

| Caso | Resultado após a correção |
| --- | --- |
| JSON com quantidade `1.9` ou ID fracionário era convertido em inteiro | HTTP 400 antes de consultar ou alterar o estoque; valores inteiros e preços decimais mantêm seu formato |
| BCrypt aceitava sufixo após os primeiros 72 bytes da senha | O encoder compartilhado recusa mais de 72 bytes UTF-8, inclusive no login e na confirmação da senha atual |
| Requisições de troca de senha atravessavam o bloqueio enquanto esperavam o lock | O bloqueio é conferido novamente após adquirir a linha do usuário |
| Estorno bloqueava medicamentos/lotes em ordem diferente da venda | Cancelamento usa medicamento, validade e lote, na mesma ordem determinística da baixa |
| Entrada entre consultas de total/disponível podia produzir saldo vencido negativo | Os dois valores são calculados na mesma consulta agregada |
| Cancelamento entre consultas do relatório podia contar a mesma venda como concluída e cancelada | Relatórios de vendas e estoque usam uma leitura consistente com REPEATABLE_READ |
| Falha da auditoria acontecia depois da confirmação de uma alteração | Mutações e auditoria de sucesso confirmam na mesma transação; falhas revertem os dados |
| Resposta de sucesso podia ser enviada antes de confirmar auditoria/transação | A resposta fica em buffer até o commit; recusas são registradas após rollback, sem corpo de formulário ou query string |
| Scanner adicionava o último produto após falha da nova busca | Enter só adiciona o resultado bem-sucedido da consulta ainda vigente |
| Respostas antigas sobrescreviam filtros atuais | Gerações descartam respostas e erros antigos em vendas, medicamentos, histórico, movimentações e relatórios |
| CSV podia exportar o relatório anterior durante carregamento/falha | Estado exportável é invalidado até a consulta atual concluir |
| Resposta de senha/cancelamento fechava um diálogo reaberto e anunciava o alvo errado | Alvo e geração são capturados antes do envio; mensagens usam o alvo original e o diálogo novo é preservado |
| Runner dependia de uma função Node do perfil e de uma lista fixa de testes | Executa node.exe diretamente e descobre todos os arquivos *.test.cjs |
